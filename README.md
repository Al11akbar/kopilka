# Копилка

Трекер аванса, ЗП и премии с сохранением в Google Таблицу.

## Как пользоваться

1. Открой сайт
2. Вставь URL веб-приложения Google Apps Script (должен заканчиваться на `/exec`)
3. Нажми «Сохранить URL»
4. Вводи суммы и жми «Сохранить в облако»

## Важно

- Используй ссылку с **/exec**, а не **/dev**
- В Apps Script при развёртывании: доступ **Все** (Anyone)
